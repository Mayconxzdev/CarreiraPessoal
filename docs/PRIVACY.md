# Privacidade e dados

O repositório público não contém o perfil, currículo, histórico de candidaturas, banco local, tokens ou remuneração real do autor. Dados versionados para demonstração devem ser sintéticos.

O aplicativo foi desenhado para operar localmente e para manter o envio final de candidaturas sob controle humano. Integrações externas e provedores de IA são opcionais e ficam sujeitos aos termos e políticas de seus respectivos serviços.

Antes de cada publicação, `scripts/public_safety_scan.py` verifica padrões de dados pessoais, IPs privados e formatos comuns de segredos. Esse scan é uma camada adicional de prevenção, não substitui revisão humana nem scanners dedicados de segurança.
